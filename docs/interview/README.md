## 🎯 使用方式

1. 先读对应的里程碑学习复盘，确认代码和测试证据
2. 再用本目录材料补充概念、替代方案和追问
3. 用户先闭卷回答，Codex 只指出遗漏、逻辑跳跃和没有证据的说法
4. 可靠答案回写到里程碑复盘；设计阶段旧答案不直接视为最终标准答案

后续整理时，以“问题 → 一句话结论 → 项目证据 → 取舍 → 限制”统一格式，逐步合并 `01` 与 `03` 的重复问题。
