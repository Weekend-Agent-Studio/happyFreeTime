# HappyFreeTime 学习文档

_记录用户对项目的真实掌握程度，并为复习、答辩和后续开发提供证据_

---

## 📍 两条独立进度线

- **代码进度：** 记录在根 [`README.md`](../../README.md)，回答功能是否已经实现和验证
- **学习进度：** 记录在 [`progress.md`](progress.md)，回答用户是否能够解释、测试和修改

代码完成不自动提升学习等级。学习等级必须由复述、自测或实验支持。

## 📚 里程碑复盘内容

每个里程碑在 `milestones/` 中维护一份持续更新的复盘，最终至少包含：

- 项目结构与端到端链路
- 核心领域模型和接口契约
- 关键设计决策与替代方案
- 测试层次和验收证据
- 实际参与的修改、实验和问题定位
- 面试 30 秒、2 分钟和深挖讲法
- 相关基础知识与高频追问
- 技术债、限制和下一步

M1 当前复盘位于 [`milestones/m1_entry_loop.md`](milestones/m1_entry_loop.md)。后续里程碑从 [`templates/milestone_review_template.md`](templates/milestone_review_template.md) 创建。

## ✍️ 更新节奏

- 每完成一个行为切片：更新掌握等级、学习证据和未决问题
- 每完成一个完整里程碑：整理完整链路、设计决策、面试表达和基础知识
- 每次复习后：只在真正能够独立回答或完成实验时提升等级
- 实现发生变化时：检查旧的面试说法和链路图是否仍然成立
