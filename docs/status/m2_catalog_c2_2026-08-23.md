# M2 Catalog C2：版本化北京 POI 快照

> 历史说明：本页描述 2026-08-23 的 36 行 CSV 方案；运行实现已由 C3 的可重建 OSM snapshot 替代，见 `m2_catalog_c3_2026-08-24.md`。

_实现与数据边界快照 · 2026-08-23；正式路线图仍以 `docs/canonical/v2_roadmap.md` 为准_

## 用户故事

无 POI Key、无网络时，HappyFreeTime 仍能从一份小型版本化 CSV 召回北京活动与餐厅，并让每个 Stop 公开来源、许可、采集时间、核验状态、价格证据和可选图片。数据不完整时系统保守降级，不伪造实时能力。

## 稳定 seam 与 Adapter

外部 seam 仍是：

```text
Catalog.recall(NormalizedConstraints) -> CatalogResult
```

`CsvCatalog` 与 `LocalFixtureCatalog` 是两个 Adapter。默认 Planning 使用 `CsvCatalog`；fixture Adapter 仅保留为离线测试与显式注入。CSV 在构造 Adapter 时一次性读取并校验，规划调用只看到强类型 `StopCandidate`。

## 数据集与许可

- 文件：`data/catalog/pois.csv`
- 数据说明：`data/catalog/NOTICE.md`（ODbL 链接、OSM attribution 和图片许可边界）
- 规模：36 条，北京活动 18、餐厅 18
- 基础来源：OpenStreetMap contributors
- 数据许可：ODbL 1.0；每行保留具体 OSM node/way/relation URL
- 坐标：CSV 保存 WGS84；Adapter 在中国大陆范围内转换为 GCJ-02，再交给当前路线 Provider
- 核验：全部 `unverified`，没有把 OSM 快照或本地估算称为现场核验
- 图片：仅一条 Wikimedia Commons CC-BY-2.0 远程引用作为契约样例，其余使用 UI 占位图

## CSV 契约

CSV 包含资源标识与类型、名称与标签、行政区和地址、经纬度与坐标系、建议停留时长、天气敏感性、价格与 `PriceKind`、人数/儿童字段、预订标记、七天基础营业时段、来源/许可/采集与核验元数据、可选 `ImageRef` 和备注。当前快照没有儿童适用性证据，因此儿童字段保持空值；建议停留时长与价格通过 `estimated_fields` 公开，标签映射、天气敏感性和预订判断通过 `derived_fields` 公开，不冒充 OSM 原始事实或 Mock 数据。

当前时段只接受 `HH:MM-HH:MM` 单区间；周六和周日必须提供。C2 明确不表达多营业区间、节假日例外、跨夜营业或临时闭店。非法坐标、时段、布尔值、重复 ID、来源缺失或图片缺许可证会让 Catalog 启动失败，而不是静默跳过坏数据。

## 价格语义

`PriceKind` 固定为：

- `known`：有可靠证据的已知价格
- `free`：可靠证据表明免费
- `estimated`：本地估算，只能用于非严格预算的粗略比较
- `unknown`：未知，`avg_price_yuan` 必须为空，不能编码成 0 元

严格预算只接受 `known/free`。`estimated/unknown` 产生 `single_resource_price_unverified` violation；若全部候选被淘汰，Planner 返回结构化预算 conflict。当前 CSV 的价格均为 `estimated`，所以严格预算返回无解是预期的可信行为。

## 图片降级

`ImageRef` 保存远程 URL、来源页、作者、许可、许可 URL 和 attribution。图片不进入 Catalog 剪枝、评分、Verifier 或 conflict。React 在没有图片或远程加载失败时显示本地样式占位图，并可跳转来源页和许可页；项目不下载、代理、缓存或永久保存第三方图片。

## 自动证据

- `tests/test_csv_catalog.py`：36 条覆盖、18/18 类型平衡、ODbL 来源、CSV 离线加载、schema 失败、WGS84→GCJ-02、图片许可与缺图降级。
- `tests/test_catalog.py`：严格预算拒绝 `estimated/unknown`，并保留原有单资源人数、儿童、营业和距离剪枝。
- `tests/test_planning.py`：默认 Catalog 使用 OSM CSV，CSV 候选可离线进入组合与 finalist 路线复核。
- `tests/test_api.py`：HTTP 公开 OSM URI、ODbL、`price_kind`、图片字段、价格未核验 violation 和严格预算 conflict。
- 后端全量回归 60/60；前端 `pnpm run build` 通过。这些不是浏览器 E2E，也不证明 POI 当前仍营业或价格准确。

## 明确不做与后续

- 不抓取大众点评/美团页面，不使用许可不明的评论、评分或图片。
- 不实现实时 POI 搜索、后台采集任务、数据库迁移、向量检索或管理后台。
- 不表达动态库存、排队、订位或购票可用性。
- C2 仅给 V1 组合器中的新 Catalog 候选中性基础分；完整多策略、质量评分和真实多样性属于 E。
- OSM 随机 plan ID 暴露了 SQLite 同秒写入后读取顺序不稳定；本切片仅为同批方案写入微秒级顺序时间戳以保持 API 顺序，没有 schema 迁移。
- 按实际到达时间验证关门边界、2/3/4 站全程预算与距离仍属于 D。
- 浏览器刷新恢复仍是 M1 已知缺口，本切片没有宣称修复。
