# S-UI1B：基础布局与视觉系统（2026-10-19）

状态：Current implementation 的开发分支诊断快照；不是 Frozen 发布或整个 S-UI1 的验收。

## 范围与基线

- 先检查干净工作树，切换 main，执行 `git pull --ff-only origin main`，从 `9be530e` 创建 `codex/s-ui1-product-frontend`。
- 主要视觉依据是本地 `happyfreetime-react-prototype-v4`；Figma 可能过时。业务语义以正式代码与测试为准。
- 本切片不修改 Planner、Router、Verifier、领域请求 Schema 或生产数据库。

## 行为变化

- 导航展开 220px、折叠 64px，折叠状态仅作为界面偏好保存；会话事实仍来自后端。Logo 区可展开，折叠按钮在 hover/focus 时显现；触屏保持可见，切换后保留键盘焦点。
- 桌面剩余工作区由聊天与详情均分；900px 及以下保留历史/详情抽屉与固定输入框。
- 条件 Chip 按日期时间、出发区域、同行人数、人均预算、出行偏好排序。编辑器仍生成原有类型化 Patch。
- 空会话显示完整品牌标题；聊天后使用聊天区独立 44px 标题，不挤占条件栏。聊天、详情、条件横向滚动与输入区分别拥有布局边界。
- 条件草稿、待验证与重规划提示从悬浮布局迁到聊天工作区正常流，避免遮挡标题。
- 建立 typography/spacing/color Tokens，删除旧外壳规则和相冲突的响应式覆盖；现有功能样式保留并改用暖白/深灰配色与统一字号。
- 导航管理独立为 `SessionNavigation`，保留新建、切换、重命名、删除。移除原先无操作行为的“设置”按钮及输入框装饰工具图标。

## 验证

- 前端 Vitest：45 passed。
- TypeScript + Vite 生产构建通过。
- Playwright 规划流与布局桌面/375px：22 passed、2 skipped（两项仅桌面布局测试在手机配置下跳过）；另有视觉捕获 2 passed，手机详情补拍 1 passed。覆盖既有规划/恢复路径、新导航折叠与刷新记忆、键盘焦点、双区等宽、固定标题/输入区、历史抽屉 ESC、窄屏横向条件滚动及 stale 提示不遮挡标题。
- 新增真实 HTTP 浏览器集成：2 passed（桌面与手机）。浏览器不拦截业务 API；Vite 转发到真实 FastAPI，使用独立临时 SQLite、DemoRouter、规则规划/推荐适配器及离线 Provider。检查生成方案、预览不改选择、选择不新建 PlanVersion、刷新恢复、取消条件编辑无 revision 变化、保存条件后旧方案 stale 且版本/选择保留。
- 首轮失败包括中文标签更改后的测试定位歧义和 Chrome 启动/页面崩溃；修正定位并串行复跑后通过。沙箱外运行浏览器测试所需的本地服务；不将这些环境故障计为业务失败率。
- 图像证据位于忽略目录 `.impeccable/review/`，包含桌面欢迎/聊天/折叠态以及手机欢迎/方案/详情。源码设计检测无机械问题。
- 独立复核指出并修正：已选按钮对比度、恢复编辑器可见分区名、会话 More 按钮覆盖重命名取消按钮；菜单改为行内布局，新增 20 条历史下的最后一条菜单/取消操作浏览器检查。手机详情截图等待入场透明度稳定后捕获，避免动画中间帧。
- 独立复核的修正判定：上述三项及最后一条菜单风险均 resolved，修正复核 disposition 为 ship；其范围是所列问题，不等于整个 S-UI1 完成。设计说明见 `frontend/DESIGN.md`。

## 复现

```powershell
pnpm --dir frontend test
pnpm --dir frontend build
pnpm --dir frontend test:e2e --workers=1
pnpm --dir frontend test:integration
git diff --check
```

集成测试需要仓库 `.venv` 中的 Python 依赖；也可用 `HFT_E2E_PYTHON` 指定解释器。使用本地 8007/4174 两个独立端口；普通开发代理仍默认 8000，可通过 `HFT_API_PROXY_TARGET` 在测试时覆盖。
